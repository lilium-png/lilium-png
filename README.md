## Привет, я lilium.png

Я делаю вещи, которыми можно пользоваться: собираю Linux-системы, разрабатываю приложения на Flutter и создаю небольшие веб-проекты. Мне нравятся выразительные интерфейсы, продуманные детали и проекты, доведённые до рабочего состояния.

## Проекты

<table>
<tr>
<td width="50%" valign="top">

### AncorOS

Кастомный Linux-дистрибутив на базе Ubuntu 26.04 LTS: GNOME 50, Wayland и собственное оформление Angelcore. Образ запускается через BIOS и UEFI, первичная настройка автоматизирована.

`Linux` `Ubuntu` `GNOME` `Wayland` `Bash`

[Открыть сайт](https://ancoros.netlify.app/) · [Исходники](https://github.com/lilium-png/AncorOS)

</td>
<td width="50%" valign="top">

### Cobarnet

Музыкальный плеер на Flutter для Windows и Android. Поиск и потоковое воспроизведение, аккаунты и библиотека, офлайн-режим со скачанными треками. Windows EXE и Android APK собраны.

`Flutter` `Dart` `Windows` `Android`

[Сайт](https://cobarnet.netlify.app/) · [Веб-плеер](https://web-cobarnet.netlify.app/)

</td>
</tr>
<tr>
<td width="50%" valign="top">

### Мафия по Bluetooth

Мобильная игра для компании: до 30 игроков и 9 ролей. Один телефон ведёт комнату, остальные подключаются локально; интернет для партии не требуется. APK собран, тесты проекта проходят.

`Flutter` `Dart` `Bluetooth` `Android`

[Страница проекта](https://github.com/lilium-png/mafia-site) · [Портфолио](https://lilium.site/)

</td>
<td width="50%" valign="top">

`HTML` `CSS` `JavaScript` `Canvas`
